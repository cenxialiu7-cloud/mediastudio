安裝步驟 · Install Guide

🍎 macOS 安裝步驟

  1. 雙擊下載好的 .dmg，把 MediaStudio 圖示拖曳到 Applications 資料夾。
  2. 到「應用程式 / Applications」對 MediaStudio 按右鍵 →「打開」。
  3. 若跳出「無法打開，因為來自未識別的開發者」，再按一次「打開」。
  4. 若仍被擋：開「系統設定」→「隱私權與安全性」→ 捲到最下方，點被封鎖的 MediaStudio 旁「仍要打開 / 強制打開」→ 輸入開機密碼。
  5. 之後就能直接雙擊開啟，不會再跳警告。

💡 看到「damaged 已損毀」只是 macOS 的下載隔離標記，照上述右鍵→打開即可，並非真的損毀；本程式原始碼公開於 GitHub。

🪟 Windows 安裝步驟

  1. 雙擊下載好的 .exe 安裝程式。
  2. 若出現藍色「Windows 已保護您的電腦」，點左下小字「其他資訊 More info」。
  3. 展開後點「仍要執行 Run anyway」。
  4. 跟著安裝精靈完成 → 桌面 / 開始功能表出現 MediaStudio 圖示。

💡 警告是因為程式未付費簽章，並非病毒。首次啟動會顯示「新手指南」，基礎功能下載即用。

主要功能 · Features

🎙

語音轉文字

用 Whisper 把影音批次轉成逐字稿與字幕（SRT / VTT / TXT）。Apple Silicon 走 Neural Engine 加速。Batch speech-to-text with Whisper.

✂️

文字驅動剪輯

像編輯文件一樣編輯影片：刪一段字就剪掉對應畫面，並可燒錄字幕。Edit video by editing its transcript.

🔇

AI 去靜音粗剪

自動偵測並移除無聲段落，長片秒變精華。Auto-remove silent gaps.

🗣

口誤聲音替換

改一句字幕文字，用克隆的講者音色重新合成並無縫拼回原片。Fix misspoken lines with a cloned voice.

🎓

聲音克隆訓練

用一段乾淨人聲訓練專屬 GPT-SoVITS 模型，產出高相似度的克隆語音。Train a personal voice model.

🔒

完全離線運行

所有處理都在本機，影音與聲音不上傳任何雲端。100% local — nothing leaves your computer.

常見問題 · FAQ

MediaStudio 是免費的嗎？

是的，完全免費、所有功能解鎖。我們透過選用性的廣告與 VPN 推薦連結支應開發成本。

安裝時出現安全警告怎麼辦？

因程式未經 Apple/Microsoft 付費簽章，系統會顯示警告。Mac 請對著 App 按右鍵 → 打開，或到「系統設定 → 隱私權與安全性 → 仍要打開」；Windows 請點「其他資訊 → 仍要執行」。

下載後可以直接用嗎？需要額外安裝什麼？

基礎功能（語音轉文字、字幕、文字驅動剪輯、去靜音）下載即用，影音處理用的 FFmpeg 已內建。聲音克隆 / 訓練等進階功能需要較大的 AI 模型（首次啟用約數 GB），程式內提供一鍵安裝精靈，全程進度顯示。

我的影片和聲音會被上傳嗎？

不會。MediaStudio 完全在本機運行，不上傳你的影音、聲音或逐字稿。本下載頁面載入第三方廣告時可能放置 cookie，詳見隱私政策。

聲音克隆 / 替換的合法使用？

請僅用於你本人聲音、或已取得當事人同意的聲音。使用者需自行遵守當地法律與肖像 / 聲音權規範，不得用於詐騙、偽冒或未授權用途。

系統需求？

macOS（Apple Silicon 體驗最佳，Intel 亦支援）或 Windows 10/11 (x64)。聲音克隆訓練建議 16GB 以上記憶體。
