macOS 安裝步驟

  1. 雙擊下載好的 .dmg，把 MediaStudio 拖曳到 Applications 資料夾。
  2. 到「應用程式」對 MediaStudio 按右鍵 →「打開」。
  3. 若跳出「來自未識別的開發者」，再按一次「打開」。
  4. 若仍被擋：「系統設定」→「隱私權與安全性」→ 最下方點「仍要打開」→ 輸入密碼。

看到「damaged 已損毀」只是 macOS 的隔離標記，照右鍵→打開即可，並非真的損毀。

Windows 安裝步驟

  1. 雙擊下載好的 .exe 安裝程式。
  2. 若出現藍色「Windows 已保護您的電腦」，點左下「其他資訊」。
  3. 展開後點「仍要執行」。
  4. 跟著安裝精靈完成 → 桌面／開始功能表出現 MediaStudio。

警告是因為程式未付費簽章，並非病毒。首次啟動會顯示「新手指南」，基礎功能下載即用。

常見問題 · FAQ

你可能想問

MediaStudio 是免費的嗎？

是的，完全免費、所有功能解鎖。我們透過選用性的廣告與 Ko-fi 贊助支應開發成本，你也可以在設定裡關閉廣告。

安裝時出現安全警告怎麼辦？

因程式未經 Apple/Microsoft 付費簽章，系統會顯示警告。Mac 請對著 App 按右鍵 → 打開，或到「系統設定 → 隱私權與安全性 → 仍要打開」；Windows 請點「其他資訊 → 仍要執行」。

下載後可以直接用嗎？需要額外安裝什麼？

基礎功能（語音轉文字、字幕、文字驅動剪輯、去靜音）下載即用，FFmpeg 已內建。聲音克隆／訓練等進階功能需要較大的 AI 模型（首次啟用約數 GB），程式內提供一鍵安裝精靈，全程進度顯示。

我的影片和聲音會被上傳嗎？

不會。MediaStudio 完全在本機運行，不上傳你的影音、聲音或逐字稿。本下載頁面載入第三方廣告時可能放置 cookie，詳見隱私政策。

聲音克隆／替換的合法使用？

請僅用於你本人聲音、或已取得當事人同意的聲音。使用者需自行遵守當地法律與肖像／聲音權規範，不得用於詐騙、偽冒或未授權用途。

系統需求？

macOS（Apple Silicon 體驗最佳，Intel 亦支援）或 Windows 10/11 (x64)。聲音克隆訓練建議 16GB 以上記憶體。
